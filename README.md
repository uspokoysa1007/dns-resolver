# dns-resolver

Рекурсивный DNS-резолвер с нуля на Go — разбор пакетов без внешних библиотек.

## Возможности (план)

- разбор и сборка DNS-пакетов вручную;
- поддержка записей A, AAAA, CNAME, MX, NS, TXT;
- рекурсивное разрешение от корневых серверов;
- кэш с TTL;
- таймауты и повторные запросы;
- CLI с выбором типа записи.

## Стек

- Язык: Go (стандартная библиотека)
- Планируемые библиотеки: только stdlib (`net`, `encoding/binary`)

## Сборка и запуск

```bash
go build -o bin/dns-resolver .
./bin/dns-resolver example.com A
```
